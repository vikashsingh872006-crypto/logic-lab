# LogicLab – Boolean Logic Simulator

A responsive, interactive learning website for Boolean logic and logic gates.

## Run it
Open `index.html` in a modern browser. No installation or build step is required.

## Deploy using GitHub Pages
1. Sign in to GitHub and create a **new public repository**. Name it `logiclab` (or another name you like).
2. On the repository page, choose **Add file → Upload files**.
3. Upload `index.html` from this folder. You may also upload this README.
4. Click **Commit changes**.
5. Open the repository's **Settings → Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**.
7. Select branch **main** and folder **/(root)**, then click **Save**.
8. Wait a minute or two and refresh the Pages section. GitHub will show your live website URL, usually:
   `https://YOUR-USERNAME.github.io/logiclab/`
9. Open that URL on your phone or laptop to test it. Share the link with your teacher/class.

## Update the website
To make changes later, open `index.html` in the repository, choose the pencil (Edit) icon, make changes, and commit. GitHub Pages republishes the site automatically.

## Features
- AND, OR, NAND, NOR, XOR, XNOR and NOT drawn with the standard logic gate symbols
- Animated signal flow along the wires and a glowing output
- Live scrolling timing diagram
- Clickable truth tables, auto demo mode and keyboard shortcuts (A / B / P / arrow keys)
- Gate symbol reference gallery
- Boolean expressions and explanations
- Responsive dark interface for mobile and desktop

No frameworks, packages, API keys, or build tools are needed.
